## 🔑 Key Learnings

1. Hardcoded product counts exist in 4+ places (×6 languages) — remember when adding products
2. Vercel CLI can deploy without git remote (`vercel --prod`), but Git integration is the durable path
3. Fine-grained PATs: `repo`-style scope ≠ push rights; SSH key management needs separate scope
4. Device flow (client_id `178c6fc778ccc68e1d6a` = GitHub CLI) works well for granting narrow scopes without pasting secrets
5. Fingerprint mismatch on GitHub SSH keys = wrong key pasted (clipboard had another key)
6. Pick **landscape** photos (≥1280×853) for product cards (4:3 crop); portraits like "Charcoal Briquettes.jpg" (1865×2267) crop poorly
7. Wikimedia Commons API pattern: `list=search srnamespace=6` → filter out PDFs → `prop=imageinfo iiurlwidth=1280` → use `thumburl`
